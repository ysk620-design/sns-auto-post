# @eigo_1phrase の投稿方針

- アカウント名：中学英語で話せる｜1日1フレーズ英会話
- 読者：英語をやり直したい大人。中学英語で話せる、すぐ使えるフレーズを求めている
- シリーズ：「直訳しがちな英語」。日本語をそのまま直訳した不自然な英語（NG例）と、場面ごとの自然な言い方を紹介する
- 1日1投稿（7枚のカルーセル）。**2026-12-31までは、これに加えて1枚まとめリールを毎日2本**（下の「1枚まとめリール」）。カルーセルから作るリール（12時台）と合わせて、リールは毎日3本になる

## 7枚の構成

1. `cover`：損したくない気持ちに訴えるフック
   - top「〇〇を」／ ng「直訳のNG例」／ bottom「って言ってない？」
   - sub に、NGな理由の一言と「正解は<span class="hl">場面でN個</span>」
2. `callout`（style: ng）：NG例の解説。title にNG例の英文、body に直訳した意味、note になぜ不自然か
3. `cards`：場面①。正解フレーズを1〜2個（[英文, 和訳]）、必要なら note で補足
4. `cards`：場面②
5. `cards`：場面③
6. `table`：まとめ早見表（最大6行。[場面, 英文]）
7. `quiz`：復習クイズ（answer は「答えはコメントで！」のまま）

## テスト回「ネイティブ度テスト」（ためしに5本）

**2026-11-22〜11-28 の7本のうち5本をテスト回にする**（通常回と交互に近い並びで。初日の11/22はテスト回）。反応を見て続けるか決めるので、この期間が終わったら週次の投稿づくりでは作らない（続けることになったら、この文を書きかえる）。

5問のテストで「あなたのネイティブ度」を判定する回。考えている間に画面を止めて見てもらい、答えのコメントやシェアにつなげる。

- 問題は、このアカウントのテーマどおり「直訳しがちな日本語」から出す。形は「「〇〇」を英語で言うと？」で、選択肢はA・B・Cの3つ（1つだけが自然な言い方、残りは直訳しがちな言い方）
- 5問は難しさを少しずつ上げる。過去に紹介したフレーズは1回のテストで1問まで（復習として）
- 判定は、ユーモアのある独自の4段階にする。英検・TOEIC・学年など実在の基準や、「〇%が間違える」のような根拠のない数字は使わない。段階の名前は回ごとに変えてよい（例：0〜1問「機内食の "Chicken or fish?" で固まるレベル」／2〜3問「ホームステイ3日目レベル」／4問「現地のカフェで常連扱いレベル」／5問「ネイティブに道を聞かれるレベル」）

8枚の構成：

1. `cover`：kicker「ネイティブ度テスト」、top は「5問中、何問わかる？」のような挑戦の一言、sub に一番上の段階の名前をちらっと見せる（例：「全問正解は<span class="hl">ネイティブに道を聞かれるレベル</span>」）。foot は「スタート →」
2〜6. `cards`：1問1枚。tag は「Q1」〜「Q5」、title に問題、cards に選択肢3つ（["A. 英文", ""] の形。和訳は書かない）。note は書かない（答えのヒントになるので）
7. `table`：tag「答え合わせ」、rows に5行（["Q1　B", "正解の英文（短い解説）"]）
8. `cta`：title「あなたのネイティブ度は？」、body に4段階（`<br>` で4行）、cta「全問正解したら、友だちにシェアして勝負してね」

- `reel_title` は「ネイティブ度テスト｜何問わかる？」のような形（30文字以内）
- **リールはクイズリールにする**：`"reel_style": "quiz"` を書く。カルーセルの画像は流さず、「問題（3択）→ 正解の発表」をくり返す専用のリールが自動で作られる。各画面の秒数は、日本語1秒6字・英語1分100語の読む速さから自動で計算される（autopost/readtime.py）。つかみ画面はなく、いきなり1問目から始まる
- `reel_questions` に、リールで出す問題の番号を書く。**長さの比べ方をためすため、5本のうち3本は `[1, 2, 3]`（約45秒）、2本は1問だけ（約18秒）にする**。1問だけの回は、正解が一番意外な問題を選ぶ（例：`[4]`）。5問すべてを出すと80秒を超えるので使わない
- クイズリールの最後の画面は、5問より少ないときは「続きの問題と判定はプロフィールの投稿で」になる（自動）
- キャプション：1行目は挑戦の一言 → 問題のテーマを1行 → 最後に次の3行

```
💬 何問わかった？コメントで教えて
📤 全問正解したら友だちにシェアして勝負
👤 日本人が直訳しがちな英語を毎日1つ → @eigo_1phrase
```

## リール

カルーセルと同じ画像から、リール動画が自動で作られて投稿される（リールタブだけに表示）。
`reel_title` に、動画の上部に固定表示するタイトルを書く（30文字以内）。形は「「〇〇」英語で言える？」（例：「「テンション上がる」英語で言える？」）

## 1枚まとめリール（2026-12-31まで毎日2本）

直訳しがちな日本語と自然な英語を縦長の1枚に並べて、BGM付きの短いリール（5秒と7秒を2日ずつ交互にして比較中）にする（止めて読む・保存する・ループして見る前提）。お金のアカウントで、この型が最後まで見られて大きく届いたので、英語でも続ける。**2026-11-25からは、伸びている1枚まとめの型を取り入れた `pop` で作る**（大きい中央タイトル・1行ごとの絵・写真の背景・カタカナの読み）。

- 毎日2本（`"post_hour_jst": 18` と `21`）、カルーセルとは別のフォルダで作る（同じ日の2本はテーマを変える。例：18時は場面別、21時は「〇〇の言いかえ」）。届く人を増やすため、2026-11-29分から1本→2本に増やした。`"type": "reel_only"`、slides は `pop` の1枚だけ（項目は autopost/pop.py の説明）
- `head` は `["日本語", "自然な英語"]`。`items` は **8〜10行**で、各行は `{"left": 日本語, "ng": 直訳しがちなNG, "right": 自然な英語, "right_sub": カタカナの読み, "icon": 絵の英語の説明}`
  - left は「」を付けず、**10文字くらいまで**。自然な英語は**20字くらいまで**の短い言い方（長いと小さくなって読みにくい）
  - right_sub のカタカナの読みは、ネイティブの発音に近い区切り（例「アイム ジャスト ルッキング」「アイ ガッチュー」）。note に「※読みは目安です」を入れる
  - icon は「a red sale price tag」のような英語の短い説明（ねんど風の絵を GitHub Actions が Gemini で作る）。文字の入るもの（看板・ロゴ）や実在のキャラクターは頼まない。同じ説明なら前の絵を使い回す
  - `rank` は使わない。`big` も使わない（根拠のない「〇割が間違える」のような数字は書かない）
- 上の部分：`kicker` は「保存版｜〇〇の場面」のようにテーマを入れる。`title` は2行で「それ、<span class="hl">通じません</span><br>〇〇の言いかえ8選」「<span class="hl">英語で出てこない</span><br>ひと言10選」のような形（「〇選」の数字は自動で大きくなる）。`bubble` は角のふきだし（12文字くらい・2行まで）。`sub` は読む人の気持ちに寄りそう一言（8行のときだけ。10行のときは入れない）
- 背景は accounts/eigo_1phrase.json の art.backgrounds から日替わり。テーマに合う背景にしたいときは `bg` に英語の説明を書く（例 "A bright airport departure hall with big windows and airplanes outside"）
- 1本ごとにテーマを決める（例：あいさつ・カフェ／レストラン・仕事・旅行・買い物・気持ち・和製英語・口ぐせ）。過去に紹介したフレーズを入れてよいのは、8行のうち3行まで（復習として）。同じ週のまとめどうしでは、同じフレーズを使わない
- キャプションは、1行目がテーマのフック → 「8つのうち、いくつ言えた？」 → 最後に次の3行

```
💬 いくつ言えたかコメントで
📌 保存して明日さっそく使おう
👤 日本人が直訳しがちな英語を毎日1つ → @eigo_1phrase
```

1行目は問いかけのフック → 要点（✕ NG例 ／ ○ 正解）→ 最後に次の3行

```
💬 クイズの答えをコメントで
```

ハッシュタグは5個（例：#英会話 #英語フレーズ #中学英語 #英語学習 #大人の英語。テーマに合わせて入れ替えてよい）

## 注意

- 企画は「思わず試したくなる・ツッコミたくなる」が先（CLAUDE.md「企画の考え方」）。「9割が間違える」「ネイティブが笑う」のような強いつかみもOK（根拠のない数字のときは「ほとんどの人が」のように言う）

- 英文はネイティブが実際に使う自然な表現にする。単語は中学英語の範囲を中心に
- 過去の投稿（queue と posted、下の「過去に投稿したテーマ」）とテーマが重ならないようにする。言い回しが違っても、同じ日本語表現を扱うものは重複とみなす

## 伸びている投稿の傾向（2026年11月、似たジャンルのアカウントを調べた結果）

- 一番反応が多いのは「カタカナ語・和製英語が、ネイティブには別の意味（失礼・変・こわい）に聞こえる」テーマ。今のシリーズの方向で合っているので、この系統を優先する
- 週に1回は、保存されやすい「場面別まとめ」にしてよい（例：職場で角を立てずに断る英語、子どもへの声かけ英語）。1つの場面にしぼって3〜5フレーズ。下の「総まとめ」とは違い、場面がはっきりしたものだけ。表紙で場面を言い切る
- 文法の説明だけの回（数えられる名詞、前置詞の使い分けなど）や、「完全保存版」のような総まとめは反応が少ない。作らない
- 表紙の sub か bottom に、驚きやちょっとした不安を誘う一言を入れる（例：「ネイティブには〇〇に聞こえるかも」「知らないと気まずい」）。ただし「8割が間違える」のような根拠のない数字は書かない
- 文字中心のアカウントでは、リールよりカルーセルの方が安定して反応がある。カルーセル中心のままにする
- 似たアカウントは朝7時台と夜21〜22時台に投稿していて、朝7時台の反応がよいアカウントもある。投稿時間は今の朝7時台のままにする
