# @eigo_1phrase の投稿方針

- アカウント名：中学英語で話せる｜1日1フレーズ英会話
- 読者：英語をやり直したい大人。中学英語で話せる、すぐ使えるフレーズを求めている
- シリーズ：「直訳しがちな英語 #NN」。日本語をそのまま直訳した不自然な英語（NG例）と、場面ごとの自然な言い方を紹介する
- 1日1投稿（7枚のカルーセル）

## 7枚の構成

1. `cover`：損したくない気持ちに訴えるフック
   - top「〇〇を」／ ng「直訳のNG例」／ bottom「って言ってない？」
   - sub に、NGな理由の一言と「正解は<span class="hl">場面でN個</span>」
2. `callout`（style: ng）：NG例の解説。title にNG例の英文、body に直訳した意味、note になぜ不自然か
3. `cards`：場面①。正解フレーズを1〜2個（[英文, 和訳]）、必要なら note で補足
4. `cards`：場面②
5. `cards`：場面③
6. `table`：まとめ早見表（最大6行。[場面, 英文]）
7. `quiz`：復習クイズ（answer は「答えはコメントで！」のまま）

## リール

カルーセルと同じ画像から、リール動画が自動で作られて投稿される（リールタブだけに表示）。
`reel_title` に、動画の上部に固定表示するタイトルを書く（30文字以内）。形は「「〇〇」英語で言える？」（例：「「テンション上がる」英語で言える？」）

## キャプション

1行目は問いかけのフック → 要点（✕ NG例 ／ ○ 正解）→ 最後に次の3行

```
💬 クイズの答えをコメントで
📌 保存して明日さっそく使おう
👤 毎日投稿中 → @eigo_1phrase
```

ハッシュタグは5個（例：#英会話 #英語フレーズ #中学英語 #英語学習 #大人の英語。テーマに合わせて入れ替えてよい）

## 注意

- 英文はネイティブが実際に使う自然な表現にする。単語は中学英語の範囲を中心に
- 過去の投稿（queue と posted、下の「過去に投稿したテーマ」）とテーマが重ならないようにする。言い回しが違っても、同じ日本語表現を扱うものは重複とみなす
