- 1日1投稿（7枚前後のカルーセル）。**2026-12-31までは、これに加えて1枚まとめリールを毎日2本**（下の「1枚まとめリール」）

## 表紙のデザイン（これまでの投稿と同じ形にする）

`cover` で次の項目を使う。

- `kicker`：小さな前置き（例：「SBI新生銀行｜こども口座キャンペーン」）
- `top`：見出し。`top_size` は 64〜72 くらい（例：「子ども名義で<br>60万円を1ヶ月預けるだけで」）
- `big`：大きな金額。単位は `<small>` で小さく（例：「+8,371<small>円</small>」）
- `sub`：補足。強調したい数字は `<b>` で金色になる（例：「口座開設特典と合わせて<br><b>最大 約1万円</b>もらえる」）
- `badge`：期限など（例：「⏰ 2027年1月31日まで」）
- `foot`：右下の誘導文（例：「条件と落とし穴 →」）
- `art`（任意）：表紙に入れるオリジナルのイラスト。テーマに合うときだけ使う
  - `food`：食べ物と値段の札（お出かけ・外食の回）。札の文字は `art_labels`（例：`["500円〜", "1,000円〜"]`）
  - `ticket`：表紙全体を家族の年パス券に見立てる（チケット・パス・入場料の回）。文字が多いときは `top_size` 64・`big_size` 150 くらいにする
  - `park`：観覧車・ジェットコースター・家族（テーマパーク・レジャーの回）
  - `calendar`：カレンダーと硬貨（毎月の金額・積み立ての回）
  - 写真・キャラクター・企業のロゴは表紙に使わない

## 7枚の構成

1. `cover`：上の形で、得する金額や結論をひと目で伝える
2. `callout`（style: ng）：よくある誤解
3. `points` または `cards`：正しい知識
4. `points` または `cards`：具体的な使い方（「こんな使い方がおすすめ」の形で）
5. `points`：注意点・デメリット
6. `table`：まとめ早見表（最大6行）
7. `cta`：コメント募集（クイズは入れない）。例：title「あなたはどっち派？」、body「コメントで教えてね」

## リール

カルーセルと同じ画像から、リール動画が自動で作られて投稿される（リールタブだけに表示）。
`reel_title` に、動画の上部に固定表示する短いタイトルを書く（30文字以内。例：「楽天NISAの乗り換えで1万円」「子ども名義で約1万円もらう方法」）

## キャプション

1行目は問いかけのフック → 要点の箇条書き → 注意点の一言 → 最後に次の3行

```
💬 コメントで教えてね
📌 保存して見返してね
👤 子育て家計のお得情報を発信中 → @gensen_otoku
```

ハッシュタグは5個

## お金の情報のルール（必ず守る）

- 金利・キャンペーンの期間や条件・制度は、必ずWeb検索で公式サイトの最新情報を確認する。確認した出典のURLと日付を review_notes に書く
- 投稿予定日までに終わるキャンペーンは扱わない
- 特定の銘柄の売買を勧めない。投資の話では、元本割れの可能性があることを注意点に入れる
- アフィリエイトや提供を含む投稿は pr を true にする（キャプションの先頭と表紙に PR 表示が入る）
- 体験談をでっちあげない。本人の実体験を入れると良い場所は、review_notes に「ここに実体験を一言」と書いて本人に任せる
- 予算の上限で早く終わることがあるキャンペーンは、キャプションに「予算の上限に達ししだい終了」と書く

## 1枚まとめリール（リールだけの投稿）

「状況 → もらえる額 → 制度名」を縦長の1枚に並べて、BGM付き約7秒のリールにする（止めて読む・保存する・ループして見る前提）。プロフィールの一覧にも出る。

- post.json は `"type": "reel_only"`、`"post_hour_jst"`（投稿する時）、slides は `matome` の1枚だけ（項目は templates.py の説明）
- items は 8〜12行。[状況, 金額, 制度名]。状況は「〜したら」「〜のとき」で、読む人が自分ごとで探せる形にする
- 金額は公式の情報で確かめ、自治体・所得で変わるものは「〜」「まで」「0円〜」などで言い切らない。note に「〇年〇月時点の目安。所得制限や自治体による違いあり」を必ず入れる
- 誇張しない（「フォローしたら年収UP」のような言い方、条件つきのものを誰でももらえるように見せる書き方はしない）
- **表紙は「数字＋損得＋意外性」**：`big` に一番目を引く数字（合計額・差額・消える額など）、`big_label` にその前置き（例「子ども1人・小学校卒業までに」「月給30万円なら」）。数字は根拠のある計算で出し、計算の内訳を note と review_notes に書く
- **数字のない行は入れない**（「会社による」「自治体による」だけの行は外す）。金額の高い順に並べて `"rank": true` で上位3つを強調する
- 切り口は「もらえる」だけでなく「消える」「差がつく」「〇〇な家なら」「実はかからない」など、意外性のある角度から選ぶ。誰でも思いつく「〜まとめ」で終わらせない
- 通常の21時のカルーセルとは別に出す。時間は通常の投稿（21時台）やリール（12時台）と重ねない

### 2026-12-31までは毎日2本（1枚まとめに集中する期間）

7秒の1枚まとめリールが、最後まで見られてループもされ、ほかのリールより大きく届いたため、年末まではこの型に集中する。

- **毎日2本**作る。`post_hour_jst` は **8**（朝）と **19**（夜）。フォルダ名は同じ日付で、短い英語名だけ変える
- この期間のカルーセルには `"reel": false` を書く（カルーセルから作るリールは出さず、リールは1枚まとめの2本だけにする）
- 2本は角度を変える（例：朝は「もらえる・申請」、夜は「消える・差がつく・期限」）。同じ週の中で、表紙の big の数字と切り口が重ならないようにする。同じ制度が別のまとめの1行に出るのはよいが、表紙の主役にするのは1回まで
- 年末の期限もの（ふるさと納税・年末調整・医療費控除・NISAの年内枠など）は12月前半に寄せる
- 2027年1月からは1日1本に戻し、カルーセルのリールも戻す（続けるかどうかは、週次レポートの結果を見て本人が決める。続けることになったら、この節を書きかえる）

## 伸びている投稿の傾向（2026年11月、似たジャンルのアカウントを調べた結果）

- 一番反応が多いのは、だれでも知っているお店やサービスの名前・具体的な数字（〇円、〇%オフ、〇%還元）・期限の3つがそろった投稿。表紙の kicker にお店やサービスの名前、big に数字、badge に期限を入れる
- 月のはじめの「今月のお得まとめ」は、毎回安定して反応がある定番になっている。毎月1〜3日のうち1日は「〇月の厳選お得まとめ」にする（キャッシュレス決済やポイントの大型キャンペーンから、還元率が高いもの・得する金額が大きいものだけを3〜5個）
- 子育て世帯向けでは、悩みの一言から入る投稿が伸びやすい（例：「児童手当、なんとなく貯めてるだけになってない？」）。キャプションの1行目や表紙の kicker に使う
- 年末調整・NISA・iDeCo の改正など、制度が変わるタイミングに合わせた解説は反応がある
- 整った図解だけだと広告に見えて指が止まりにくい。表紙の kicker や top には、読む人の気持ちに寄りそう一言を入れる（例：「正直、これ知らないと損します」「子どもの医療費、もらい忘れてない？」）。「我が家も乗り換えました」のような体験の言葉は本人の事実のときだけ使い、使えそうなら review_notes で本人に確認する
- 家計簿や資産を公開する投稿は、本人の実際の数字が毎回必要なので作らない（数字を公開せず、お得情報だけで伸びているアカウントも多い）
- 「コメントで〇〇と送ってくれたら詳しくDMで送ります」という形はコメントが大きく増えるが、DMを自動で返す仕組みがないので使わない
- リールよりカルーセルの方が安定して反応がある
