## 表紙のデザイン（これまでの投稿と同じ形にする）

`cover` で次の項目を使う。

- `kicker`：小さな前置き（例：「SBI新生銀行｜こども口座キャンペーン」）
- `top`：見出し。`top_size` は 64〜72 くらい（例：「子ども名義で<br>60万円を1ヶ月預けるだけで」）
- `big`：大きな金額。単位は `<small>` で小さく（例：「+8,371<small>円</small>」）
- `sub`：補足。強調したい数字は `<b>` で金色になる（例：「口座開設特典と合わせて<br><b>最大 約1万円</b>もらえる」）
- `badge`：期限など（例：「⏰ 2027年1月31日まで」）
- `foot`：右下の誘導文（例：「条件と落とし穴 →」）

## 7枚の構成

1. `cover`：上の形で、得する金額や結論をひと目で伝える
2. `callout`（style: ng）：よくある誤解
3. `points` または `cards`：正しい知識
4. `points` または `cards`：具体的な使い方（「こんな使い方がおすすめ」の形で）
5. `points`：注意点・デメリット
6. `table`：まとめ早見表（最大6行）
7. `cta`：コメント募集（クイズは入れない）。例：title「あなたはどっち派？」、body「コメントで教えてね」

## リール

カルーセルと同じ画像から、リール動画が自動で作られて投稿される（リールタブだけに表示）。
`reel_title` に、動画の上部に固定表示する短いタイトルを書く（30文字以内。例：「楽天NISAの乗り換えで1万円」「子ども名義で約1万円もらう方法」）

## キャプション

1行目は問いかけのフック → 要点の箇条書き → 注意点の一言 → 最後に次の3行

```
💬 コメントで教えてね
📌 保存して見返してね
👤 子育て家計のお得情報を発信中 → @gensen_otoku
```

ハッシュタグは5個

## お金の情報のルール（必ず守る）

- 金利・キャンペーンの期間や条件・制度は、必ずWeb検索で公式サイトの最新情報を確認する。確認した出典のURLと日付を review_notes に書く
- 投稿予定日までに終わるキャンペーンは扱わない
- 特定の銘柄の売買を勧めない。投資の話では、元本割れの可能性があることを注意点に入れる
- アフィリエイトや提供を含む投稿は pr を true にする（キャプションの先頭と表紙に PR 表示が入る）
- 体験談をでっちあげない。本人の実体験を入れると良い場所は、review_notes に「ここに実体験を一言」と書いて本人に任せる
- 予算の上限で早く終わることがあるキャンペーンは、キャプションに「予算の上限に達ししだい終了」と書く

## 伸びている投稿の傾向（2026年11月、似たジャンルのアカウントを調べた結果）

- 一番反応が多いのは、だれでも知っているお店やサービスの名前・具体的な数字（〇円、〇%オフ、〇%還元）・期限の3つがそろった投稿。表紙の kicker にお店やサービスの名前、big に数字、badge に期限を入れる
- 月のはじめの「今月のお得まとめ」は保存されやすい定番になっている。毎月1〜3日のうち1日は「〇月の厳選お得まとめ」にする（キャッシュレス決済やポイントの大型キャンペーンから、還元率が高いもの・得する金額が大きいものだけを3〜5個）
- 子育て世帯向けでは、悩みの一言から入る投稿が伸びやすい（例：「児童手当、なんとなく貯めてるだけになってない？」）。キャプションの1行目や表紙の kicker に使う
- 年末調整・NISA・iDeCo の改正など、制度が変わるタイミングに合わせた解説は反応がある
- 家計簿や資産を公開する投稿は、本人の実際の数字が毎回必要なので作らない（数字を公開せず、お得情報だけで伸びているアカウントも多い）
- 「コメントで〇〇と送ってくれたら詳しくDMで送ります」という形はコメントが大きく増えるが、DMを自動で返す仕組みがないので使わない
- リールよりカルーセルの方が安定して反応がある
