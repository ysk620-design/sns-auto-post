# @kaigai_hokkori 投稿方針

名前：海外の反応｜日本のほっこり話
内容：海外の人が日本で驚いた・感動した「ほっこりする話」を、短いストーリーと海外の声で紹介する。読んだ人が「日本っていいな」と思える話にする。

## 投稿の時間

- カルーセルは毎日20時台（夜のくつろぎ時間）、リールは翌日の12時台（昼休み）
- 立ち上げの 2026-11-16 までは1日2本（カルーセルは朝7時台と夜20時台、リールは12時台と18時台）。週次の投稿づくりで作るのは、これまでどおり1日1本

## 形式（type は "story"）

見本は `examples/kaigai_hokkori/post.json`。ほかのアカウントと違い、`slides` は書かない。次の項目から、アメコミ風のカルーセル（8〜9枚）と、読み上げ付きのリール（約40秒）が自動で作られる。

- `icon`・`burst`・`top`・`big`（・`big_size`）：表紙。`top` は1行、`big` は `<br>` で2行。結末は書かず「まさかの結末！」のように続きが気になる形にする
- `scenes`：場面をちょうど4つ（起承転結。ただし画面に「起承転結」とは書かない）。各場面に `title`（短い見出し）、`mood`（旅行者の表情：wow / happy / love / sad / think）、`say`（ふきだし。1行に収まる長さ）、`nar`（説明。`<br>` で2行）。店員や警察官を出すときは `clerk`（表情）、警察官は `"police": true`、子どもは `"kid": true`、服や髪の色は `look`。小物は `prop`
- `comments`：海外の声を3〜6個。`[国旗の絵文字, だれの声か, コメント]`。国がわからないときの絵文字は 🌏
- `stat`：「実は…」のページ。数字を2つ（`l1`/`n1`、`l2`/`n2`）と、ひとこと（`msg`）、出典の名前（`src`）
- `cta`：最後の問いかけ（`<br>` で3行くらい）。キャプションの 💬 の行と同じ問いにする
- `chat_title`：リールのチャット画面の見出し。強調したい言葉を `<em>` で囲む
- `reel_script`：リール用。`comments` は3つだけ（カルーセルより短く言い直してよい）。`nar` は読み上げ台本でちょうど10行（表紙・場面4つ・海外の声3つ・実は…・締め の順に、1画面1行）
- `sources`：海外の声と数字の出典（URL入り）。画像やキャプションには出ない
- 使える小物（`icon` と `prop`）：wallet, wagyu, sushi, watch, ramen, noren（`"noren:鮨"` のようにのれんの文字を指定できる）, question, koban, ball, trash, crane, sandwich, train, phone, bag, shinkansen, broom, coffee。話に合う小物がなければ、近いものか question を使う
- 文字の装飾に使えるのは `<br>` と `<em>` だけ

## 内容のルール

- **話は実話をもとにする**（画像に「実話をもとに再現」と出る）。場面は再現なので細部を補ってよいが、無理のない「あり得る話」にとどめ、実在の人の発言を勝手に作らない
- **海外の声は、記事・口コミ・SNSなどに実際に載っているコメントだけ**を短く訳す。それらしい声を作らない。Web検索で確認し、出典のURLを `sources` に書く。だれの声かは「ロンドンのフードブロガー」「現地紙より」のように、わかる範囲で書く
- 数字（`stat`）も必ず出典で確認し、確認日を `review_notes` に書く
- 「フィクション」「※イメージ」といった表記は入れない
- 他国や外国人を下げて日本を持ち上げる書き方はしない。驚きと感謝が伝わる、気持ちのよい話にする
- 系統をばらけさせる（神対応／本場の味／マナー／日本のモノ／やさしさ など）。同じ系統を2日続けない
- 読み上げ台本（`reel_script.nar`）は耳で聞いてわかる文にする。読み間違えそうな言葉はひらがなにする（例：「3つに2つ」→「みっつにふたつ」、「iPhone」→「アイフォン」）。数字は「約5500頭」のようにカンマなしで書く。読み方が心配な言葉は `review_notes` に書く
- キャプション：1〜2行目で話の入り、次に海外の声や数字をひとつ、最後に次の3行を入れる

```
💬 （cta と同じ問いかけ）
📌 保存して友だちにシェア
🌏 海外が驚いた日本のいい話を毎日お届け → @kaigai_hokkori
```

- ハッシュタグは5個まで。`#海外の反応 #日本の良いところ #ほっこり` ＋ その回のテーマ2つ
- `reel_title` は書かない（リールは専用の画面で作られる）。音声のクレジット（VOICEVOX:冥鳴ひまり）は、リールの最後の画面とキャプションに自動で入る
